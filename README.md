# 3D Sneaker Store

Django-сайт магазина кроссовок с интерактивным просмотром 3D-моделей через Three.js. Главная страница показывает каталог, а карточка товара открывает GLTF-модель с автоповоротом, приближением и управлением мышью.

## Возможности

- Главная витрина с подборкой кроссовок.
- Детальная страница товара с ценой, размерами, описанием и 3D viewer.
- Регистрация и вход пользователей.
- Корзина для зарегистрированных пользователей.
- Избранное для зарегистрированных пользователей.
- Подключение `three.js`, `GLTFLoader` и `OrbitControls` через import map.
- Загрузка модели из `static/sneakers/models/scene.gltf`.
- Резервная процедурная 3D-модель, если GLTF-файл не загрузился.
- Django admin для добавления товаров и указания пути к модели.

## Структура

```text
sneaker_store/            # настройки Django-проекта
sneakers/                 # приложение магазина
static/sneakers/css/      # стили интерфейса
static/sneakers/js/       # Three.js viewer
static/sneakers/models/   # GLTF/BIN/texture файлы модели
README.md
requirements.txt
manage.py
```

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

После запуска сайт будет доступен по адресу `http://127.0.0.1:8000/`.

## Как заменить 3D-модель

1. Положите файлы модели в `static/sneakers/models/`.
2. Если модель использует текстуры, сохраните их рядом или в подпапке `textures/`, как в текущем примере.
3. Укажите путь к основному `.gltf` или `.glb` файлу в поле `model_path` товара, например:

```text
sneakers/models/my-sneaker/scene.gltf
```

Viewer получает путь из Django-шаблона через `data-model-path` и загружает модель в `static/sneakers/js/viewer.js`.

## Загрузка фото и 3D-моделей через сайт

Для новых товаров можно не копировать модель в `static` вручную. Администратор может загрузить файлы через форму товара:

- `Картинка для каталога` - фото кроссовок для карточки товара.
- `Файл 3D модели` - `.glb` файл для Three.js viewer.
- `Путь к 3D модели в static` - запасной вариант для старых моделей из `static`.

Загруженные файлы сохраняются в `media`:

```text
media/sneakers/images/<slug>/
media/sneakers/models/<slug>/
```

Для загрузки через сайт используйте `.glb`, потому что этот формат хранит геометрию, материалы и текстуры в одном файле. `.gltf` с отдельными `.bin` и текстурами лучше хранить в `static` и указывать путь через поле `model_path`.

## Админка

Создайте администратора:

```bash
python manage.py createsuperuser
```

Затем откройте `http://127.0.0.1:8000/admin/` и добавьте товары в разделе "Кроссовки". Если база пустая, сайт показывает встроенные демо-товары из `sneakers/catalog.py`.

## Добавление кроссовок через сайт

На сайте есть система входа и форма добавления товара без перехода в Django admin.

1. Создайте администратора или staff-пользователя:

```bash
python manage.py createsuperuser
```

2. Войдите на странице `http://127.0.0.1:8000/accounts/login/`.
3. После входа в шапке появится ссылка "Добавить".
4. Откройте `http://127.0.0.1:8000/sneakers/add/` и заполните форму.

Обычные пользователи без прав `is_staff` или `is_superuser` не могут открывать форму добавления.

## Панель управления на сайте

Администратор может управлять каталогом без Django admin:

- Обзор панели: `http://127.0.0.1:8000/manage/`
- Список товаров: `http://127.0.0.1:8000/manage/sneakers/`
- Добавление товара: `http://127.0.0.1:8000/sneakers/add/`
- Редактирование и удаление доступны из списка товаров.

В панели есть поиск по названию, бренду, категории и расцветке, фильтр по бренду, статистика по товарам, пользователям и избранному.

## Пользователи, корзина и избранное

- Регистрация: `http://127.0.0.1:8000/accounts/signup/`
- Вход: `http://127.0.0.1:8000/accounts/login/`
- Корзина: `http://127.0.0.1:8000/cart/`
- Избранное: `http://127.0.0.1:8000/favorites/`

Обычный зарегистрированный пользователь может добавлять кроссовки в корзину и избранное. Добавлять новые товары через сайт может только пользователь с правами `is_staff` или `is_superuser`.
